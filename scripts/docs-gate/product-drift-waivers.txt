# Gate C.6 — 产品口径漂移豁免登记（waivers）
#
# 用途：本文件让 Gate C.6 可以「今天就是 hard（阻断构建）」，同时不为存量问题
#       制造假绿。任何 C.6 违规想放行，都必须在这里登记，并且必须带上：
#         owner（谁负责解决）+ expires（到期日）+ reason（为什么不现在就改）
#
# 格式：<rule>|<subject>|<owner>|<expires YYYY-MM-DD>|<reason>
#   - `#` 开头的行是注释；
#   - 到期日采用字典序比较（YYYY-MM-DD 字符串天然可比）；
#     expires 与 today **同日**仍判定为有效 —— 完整当天保留给 owner 收尾；
#     次日（expires+1）立即反向 FAIL，无宽限期。
#   - 豁免是**债务登记**，不是解决方案。到期前必须二选一：修掉，或重新拍板。
#
# 本文件是长期机制：允许「已知且被认领」的漂移存在，不允许「无人认领」的漂移存在。
