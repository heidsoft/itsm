# CMDB 商业化 MVP 与生产验收门槛

## 产品边界

CMDB 正式产品面只展示已经通过生产验收的 GA 能力。代码中存在接口、表或页面，
不代表该能力可以对客户承诺。能力状态的前端单一事实来源为
`src/lib/cmdb/cmdb-capabilities.ts`。

### 当前 GA 范围

- CI 类型与属性模板
- 配置项录入、查询、编辑、生命周期和历史
- CI 关系维护
- 拓扑和影响分析

### 当前受控试点范围

- 云账号和云服务目录
- 云资源自动发现
- Service Graph Registry
- 云资源与 CI 自动对账

受控试点能力不进入正式导航。自动发现接口必须失败关闭，禁止创建不会被执行、
长期停留在 `pending` 的任务。

## 云同步转 GA 的强制验收条件

1. 至少一个真实厂商适配器完成账号连接测试和跨 Region 分页发现。
2. 凭证由密钥服务引用，API、日志和审计响应不得返回明文凭证。
3. 发现任务具备 pending、running、succeeded、failed、cancelled 状态和合法转换。
4. 每个任务记录开始时间、结束时间、发现数量、创建、更新、失联和失败数量。
5. 相同来源和资源标识重复执行不产生重复 CI。
6. 单 Region 失败可重试，部分失败不得被报告为成功。
7. 资源失联先进入待治理状态，不允许静默物理删除。
8. 字段冲突遵守来源优先级，并保留变更前后值和执行批次。
9. 所有查询、任务、资源、结果和对账记录强制 tenant 过滤。
10. 10 万 CI、50 万关系规模下完成约定的性能和稳定性测试。

## 阿里云试点运行配置

阿里云试点必须使用安全引用 `env://ITSM_ALIYUN`，禁止把 AccessKey JSON 保存到
`credentialRef`。服务运行环境需要配置：

```bash
ITSM_ALIYUN_ACCESS_KEY_ID=...
ITSM_ALIYUN_ACCESS_KEY_SECRET=...
# 使用 STS 时配置
ITSM_ALIYUN_SECURITY_TOKEN=...
```

连接验证命令：

```bash
cd itsm-backend
go run ./cmd/aliyun-connection-check
```

SDK 调用设置 5 秒连接超时、15 秒读取超时且不自动重试。生产网络必须能够访问
`*.aliyuncs.com`；如果开发机配置了不可用的 HTTP 代理，应将阿里云 API 域名加入
`NO_PROXY`，不得通过禁用 TLS 校验绕过网络问题。

## 生产验收场景

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| CMDB-ACC-001 | 类型建模后录入 CI | 必填、唯一性和动态属性校验在 API 与 UI 一致生效 |
| CMDB-ACC-002 | 批量导入 | 支持预检、逐行错误、部分成功统计和可恢复重跑 |
| CMDB-ACC-003 | 关系与拓扑 | 循环关系不会导致无界遍历，深度和节点上限生效 |
| CMDB-ACC-004 | 影响分析 | 事件和变更引用相同 CI 时得到一致的租户内影响范围 |
| CMDB-ACC-005 | 生命周期与历史 | 每次修改保留操作者、来源、前后值和时间 |
| CMDB-ACC-006 | 跨租户访问 | 列表、详情、关系、拓扑、导入导出和后台任务全部失败关闭 |
| CMDB-ACC-007 | 云账号凭证 | 创建后仅返回掩码和健康状态，日志无明文密钥 |
| CMDB-ACC-008 | 重复云发现 | 连续执行两次不新增重复 CI，第二次只产生必要更新 |
| CMDB-ACC-009 | 部分发现失败 | 任务标记失败或部分失败，可定位 Region 并安全重试 |
| CMDB-ACC-010 | 数据恢复 | 备份恢复后 CI、关系、历史和任务批次一致 |

## 发布规则

任何 pilot 能力转为 GA，必须同时提交：能力状态变更、后端服务测试、跨租户测试、
前端契约测试、端到端验收测试以及运维手册。缺少任一项时保持 pilot。
