基准 `021f08c0e`，2026-11-28。下列浏览器场景均待执行。使用独立本地部署和两个测试租户，准备申请人、工程师、独立审批人及管理员。每次保存运行版本、viewport、trace、脱敏日志及有 UI 变更时的前后截图。

| 场景 | 成功和失败断言 |
| --- | --- |
| 普通用户创建，工程师接单至关闭 | 审核界面、详情与历史一致；刷新、双击、网络重试、并发版本写入只产生一次副作用 |
| 独立审批、驳回和申请人自审 | 审批人可表决；申请人直接请求被拒；驳回及重复投票返回稳定状态，审计与任务一致 |
| 服务目录申请交付及动态表单 | 验证数据库账号、项目、应用权限、网络接入、故障报障。检查必填、类型、提交、持久化、详情、搜索和审计。重复安装及升级保留客户配置 |
| 分配和自动化 | 匹配与不匹配、优先级、模拟无写入、执行历史、重复事件、循环与拒绝高风险动作 |
| BPMN 和 SLA | 暂停、恢复、终止、失败重试、任务超时和业务投影收敛；SLA 超时与通知可追踪且去重 |
| AI 草稿与确认 | 生成和补齐不落单，确认后仅一张，失败可继续手动创建 |
| 隔离及协作 | 两租户交叉访问失败。同一租户按可见性区分评论、附件、内部历史、关联、工作台及搜索 |
| UI | 1280×720、1440×900、1920×1080，浏览器缩放、深色模式、键盘操作，逐项比对 UI 审计 |
