## 首发场景（锁定一个，做深做透）

**AI Email-to-Ticket**：邮件 → 解析 → 自动建单 / 分类 / 路由 / 建议处理。
理由：痛点普遍、演示直观、可量化（建单耗时、准确率、人工介入率）。

## PoC 标准流程

1. **场景锁定**：与客户确认 1 个真实邮件源 + 1 个工单域。
2. **验收指标定义**（见 templates/POC_ACCEPTANCE）：
   - 邮件→工单自动建单率（目标 ≥ 90%）
   - 分类准确率（目标 ≥ 85%，人工可纠偏）
   - 平均处理时长下降比例（待基线）
   - 人工介入率（目标 ≤ 15%）
3. **周期**：建议 2–4 周，含部署 + 调优 + 验收。
4. **交付物**：Demo 录像、验收报告、改进建议、报价转正式合同路径。

## 红线

PoC 不承诺"全自动无人值守"（§0.3 原则 2：生产可靠性 > 自治）；关键动作保留人工确认与审计。
