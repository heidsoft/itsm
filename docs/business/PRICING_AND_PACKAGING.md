## 双轨模型（已对齐官网 pricing.html）

### 轨一：开源永久免费（Apache-2.0 自托管）

- 核心 ITSM / CMDB / 知识库 / 连接器 / MCP 全部开源。
- 安全底线、租户隔离、基本审计、数据可迁移性 **不锁在付费版**（§3.2 / §6.2）。
- 用户自行 `docker-compose` 部署，社区支持。

### 轨二：企业服务（按需，合同约定）

| 服务 | 建议测试价（年） | 说明 |
|---|---|---|
| 私有化部署 | **10–30 万起** | 核心交付形态，非付费附加项（§3.2） |
| 专业服务 | **2–10 万** | 实施 / 定制 / 培训 |
| 企业版支持 | **8–20 万/年起** | SLA、专属客户成功、优先修复 |
| 付费 PoC | **1.5–3 万/项目** | 锁定首发场景做可收费闭环验证（§5.3） |

> 注：手册 §5.2 另列 Professional **1.98–4.98 万/年** 档，可纳入后续打包讨论；当前对外仅以"开源免费 + 企业服务按需"双轨呈现，避免与"v1.6.57 未 GA"口径冲突。
