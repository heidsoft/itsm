## 目标

- 用"开源可自托管 + 透明路线图 + 活跃社区"建立信任（§6.1）。
- 把内容流量（公众号 / 官网 / 技术文章）转化为部署与贡献（§7.3）。

## 运营节奏（建议，待填真实数据）

- **周**：Issue/PR triage（见 ISSUE_TRIAGE）、社区答疑。
- **双周 / 月**：发布节奏、Roadmap 同步、公众号技术文。
- **季度**：标签体系 review（label-schema §10）、指标复盘（COMMUNITY_METRICS）。

## 内容转化路径（§7.3）

每篇对外内容结尾应含 CTA：部署 Demo → 申请 PoC → 商业支持，三选一。

## 待填字段

- 真实发布日历、公众号选题池、官网/公众号引流漏斗数据。
- 贡献者激励与首位外部贡献者转化案例。

## 红线

不刷 Star、不编造采用案例；社区信号（Star/Contributor）须真实（见 COMMUNITY_METRICS）。
