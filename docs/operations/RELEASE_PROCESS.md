## 版本语义

- 语义化版本：major(破坏性, `breaking-change`) / minor(新能力) / patch(修复)。
- `CHANGELOG.md` 已极详尽（~900KB），每次发布须同步更新。

## 发布检查单（待填真实项）

- [ ] 变更归类并写入 CHANGELOG
- [ ] 标签 / Roadmap 同步
- [ ] 文档（README / docs）与代码一致
- [ ] e2e / 契约测试通过
- [ ] 安全扫描无高危

## GA 门槛（严守口径）

- 当前 **v1.6.57 生产加固未 GA**。任何对外文案、定价、Roadmap 不得宣称 GA。
- GA 判定条件须由维护者明确（如：核心场景 e2e 通过率、SLA、审计、迁移工具齐备）后方可放宽。

## 待填字段

- 真实发布节奏（周/双周/月）、灰度策略、回滚预案。

## 红线

不擅自升 v1.6.58 直到满足 GA 门槛；不宣称 GA、不写"替代 ServiceNow"。
