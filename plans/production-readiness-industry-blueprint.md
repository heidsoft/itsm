# 生产级部署与行业拓展蓝图（2026 Q3 起）

> 目标:使开源 ITSM 达到**生产级可部署**,并能在**电商、工业、医疗、零售、物流**行业企业落地。
> 与 [ROADMAP.md](../ROADMAP.md) v1.6.x(可靠性)/ v1.7(连接器与 E2E)衔接,与
> [architecture-understanding 评审](../docs/architecture/review-2026-08/architecture-understanding.md) 的风险登记册对应。
> 原则:行业化通过**扩展点**(服务目录模板、BPMN 模板、CMDB CI 类型、连接器、seed)实现,**不 fork 核心数据模型**。

## 阶段总览

| 阶段 | 主题 | 依赖 | 对应版本 |
|---|---|---|---|
| P1 | 架构收敛:单一生产入口 + 边界强制 | 无 | v1.6.x |
| P2 | 生产可靠:部署/备份/可观测/安全/性能 | P1 | v1.6.x → v1.7 |
| P3 | 行业就绪:模板包 + 行业 CI 类型 + 合规基线 | P2 部分可并行 | v1.7 |
| P4 | MSP/SaaS 商业化(计费、多区域) | P2/P3 | v2.0(已有计划,不展开) |

## P3 行业就绪(约 4-6 周,与 P2 后半段并行)

行业差异通过 5 类扩展点承载,核心模型零分叉:

| 扩展点 | 内容 |
|---|---|
| 服务目录模板包 | 行业化服务项 + 请求模板(幂等 seed,只建模板不建假业务数据) |
| CMDB CI 类型模板 | 行业 CI 类型、关系类型、发现源适配 |
| BPMN 流程模板 | 行业审批链、重大事件、变更冻结流程 |
| SLA 策略模板 | 7x24(零售/物流)、营业时段分级、合规时限 |
| 连接器优先级 | 飞书/企微/钉钉(既有计划)+ 监控告警 Webhook(全行业)+ 行业平台对接预留 |

### 五行业切入要点

> 完整需求分析、能力匹配矩阵与切入次序见 [行业业务需求分析](../docs/product/industry-verticals-analysis-2026-08.md)。
> 次序:**零售/电商 → 物流(复用 ~80%) → 工业(需告警接入/作战室) → 医疗(需通过安全与连续性门禁)**。

| 行业 | 典型场景 | 关键诉求 | 模板包侧重 |
|---|---|---|---|
| 零售/电商 | 门店/仓配 IT、POS 与支付故障、大促变更冻结 | 多门店多租户、7x24、高峰保障、告警即事件 | 事件分级 + 重大事件流程 + 变更冻结 |
| 物流 | 分拣设备、巴枪/车载终端、网点网络中断 | 四级网点层级、时效升级、移动优先 | 网点类 CI + 升级矩阵 + 飞书/企微入口 |
| 工业制造 | OT/IT 融合、产线停机、巡检工单 | 停机=最高优先级、倒班值守、告警自动开单 | 产线设备 CI 类型 + 停机影响分析 + on-call |
| 医疗 | HIS/EMR/PACS/LIS 服务中断、临床区域终端、跨厂商协同 | 诊疗连续性、敏感数据最小化、受控应急访问、7x24 | 关键业务服务 CI + 医疗重大事件 + 维护窗/回退 + 委派访问 |
| 跨行业共性 | 移动/IM 轻入口、告警接入、重大事件协同、报表度量包 | 私有化部署、审计、数据驻留 | 共性差距优先于行业模板 |

### 合规基线(所有行业)

- 审计日志覆盖:登录、越权尝试、AI 建议采纳、连接器动作、批量操作(现有机制核对一遍完整性)
- 数据驻留与私有化:文档明确最小外部依赖(可不依赖公网)
- 医疗专项:敏感数据分类/脱敏、break-glass、厂商委派范围、恢复演练与审计证据；AI 禁止作临床决策

**验收标准**:至少零售/电商一个行业完成完整模板包 + 端到端演练;其余行业模板包骨架进入种子数据。
